# RAG 임시 테스트 화면

이 폴더는 `src/rag`의 순수 Python 계약을 화면에서 시험하기 위한 임시
Streamlit 앱입니다. `backend/`나 HTTP API를 사용하지 않습니다.

## 실행

Miniforge Prompt에서 프로젝트 루트로 이동한 뒤 실행합니다.

```bat
cd /d C:\Users\Playdata\Desktop\SKN28-FINAL-2Team
rag_test_frontend\run_rag_test_ui.bat
```

또는 직접 실행할 수 있습니다.

```bat
conda activate dl_nlp_env
cd /d C:\Users\Playdata\Desktop\SKN28-FINAL-2Team
python -m streamlit run rag_test_frontend\app.py --server.port 8501
```

브라우저가 자동으로 열리지 않으면 `http://localhost:8501`에 접속합니다.

## 시험할 수 있는 흐름

1. 선택 폼으로 최초 여행 조건 전달
2. 자연어 조건을 선택 폼과 함께 전달
3. 식사 후보 부족 시 검색 반경 확대 또는 해당 식사 제외
4. `그냥 식사 장소를 빼 주세요.` 자연어 후속 요청
5. 완료 일정에서 `2일차 ○○를 다른 곳으로 교체해 주세요.` 부분 수정
6. 정규화된 조건, 검색 후보 수, 검증 결과, 전체 응답 JSON 확인
7. 왼쪽 `RAG 평가` 메뉴에서 골든셋 기반 자동 평가 실행
8. 통과율, 평균 점수, 지표별 평균, 실패 태그, 응답시간 확인
9. 선택적으로 OpenAI LLM 심사를 추가하고 API 토큰 사용량 확인
10. 평가 결과를 JSON 또는 Markdown 보고서로 다운로드
11. 임의 질문을 기본 LLM과 RAG에 동시에 전달해 A/B 비교
12. 조건 준수, 관련성, 근거성, 일정 실행 가능성, 설명 품질 점수 확인
13. 두 답변의 전체 점수, 개선폭, 평가 근거를 JSON으로 다운로드
14. 동일 질문 평가 횟수를 1~120회로 지정
15. 평균·표준편차·최소·최대 점수, 승패 횟수, 회차별 변동 확인

## 평가 화면 주의사항

- 기본 평가도 실제 RAG를 실행하므로 선택한 케이스에 따라 OpenAI, MySQL,
  ChromaDB 및 지도 API를 사용할 수 있습니다.
- `LLM 심사 추가`는 기존 RAG 실행 외에 정성 평가용 OpenAI 호출을 한 번 더
  수행하므로 비용이 추가됩니다.
- `임의 질문 A/B 비교`는 RAG 파이프라인 호출에 더해 기본 LLM 답변 1회와
  익명 비교 심사 1회를 평가 횟수만큼 호출합니다.
- 10회를 초과하는 반복 평가에는 화면의 대량 API 실행 확인이 필요합니다.
- A/B 평가 모델에는 답변 출처를 숨기고 `답변 A`, `답변 B`로 전달하지만,
  LLM 심사는 인간 평가를 완전히 대체하지 않으므로 중요한 결과는 사람이
  표본 검수해야 합니다.
- 빠른 확인은 조건 추출 케이스 1~2개와 반복 1회로 시작하고, 전체 회귀
  평가는 모든 케이스를 선택해 실행하는 방식을 권장합니다.

## 삭제

됩니다. 다른 소스에는 의존 파일을 추가하지 않았습니다.
